FAQ

Before you install.

Short answers to the important stuff.

Is Recon 7 free?

Yes. The current Windows build is intended to be free to download and use.

Does Recon replace Chrome or Edge?

That is the goal: a standalone browser experience with its own interface and feature set.

Does Recon guarantee downloads are virus-free?

No. Recon Check is intended to add another safety layer, but no scanner or browser can guarantee every malicious file will be caught.

Why does Windows sometimes warn about new apps?

New or unsigned Windows applications can trigger reputation warnings until they are code-signed and establish reputation. Recon’s release process is being improved around this.

Can I uninstall Recon?

Yes. Production installer builds are intended to include a normal Windows uninstall path.
