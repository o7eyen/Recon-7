RECON 7 // RELEASE NOTES

Early access status.

The Recon 7 website is hosted from the public GitHub repository. Windows installers are released separately through GitHub Releases so the website never points to a file before it actually exists.

Current focus

  • Stable browsing and smooth tab/search interactions
  • Download prompts and Recon Check security UX
  • Profile, review, rating and private messaging concepts
  • Media discovery and AI playlist ideas
  • Normal Windows uninstall support for installer builds

Security note

Recon is intended to be a safe browser, but no browser, antivirus engine or download scanner can guarantee protection against every malicious file, exploit or credential theft attempt. Treat Recon Check as an extra layer, not a guarantee.

Windows reputation warnings

Unsigned or newly distributed Windows applications can trigger Microsoft reputation warnings. The correct long-term solution is code signing and building software reputation, not disabling Windows security protections.
